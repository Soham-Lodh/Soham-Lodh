## About

Backend-focused engineer building production systems across APIs, databases, authentication, and ML inference.

I enjoy working on problems involving **performance, concurrency, system architecture, and reliable backend design**. My recent work spans multi-tenant systems, event-driven workflows, high-concurrency APIs, and production ML services.

Currently focused on becoming better at designing systems that remain **fast, predictable, and maintainable under real usage**.
